# Personal Portfolio Website

A responsive personal developer portfolio built with HTML5, CSS3, and JavaScript, featuring dark/light theme toggling and an interactive neural-network canvas background.

 **Live Demo:** [guileless-phoenix-f4aad4.netlify.app](https://guileless-phoenix-f4aad4.netlify.app)

##  Built With
- **HTML5 & CSS3** (Custom CSS variables, CSS Grid/Flexbox, responsive layout)
- **JavaScript** (Interactive canvas animation and theme switcher)
- **Hosted on:** Netlify
