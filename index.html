Featured Projects

ESP32 Drone Flight Controller

The ESP32-Based Drone Flight Controller is an embedded systems project developed at Dnyanvilas College of Engineering (DVCOE), affiliated with Dr. Babasaheb Ambedkar Technological University. The project focuses on developing a drone flight control system using the ESP32 microcontroller and the LiteWing drone kit. The system integrates an ESP32 DevKit, MPU6050 motion sensor, brushless motors, and Electronic Speed Controllers (ESCs) to form the core hardware setup. The ESP32 serves as the main controller, while the MPU6050 provides motion and orientation data. The system is designed around the interaction between sensor inputs, microcontroller processing, and motor control. This project provided practical experience in embedded programming, sensor interfacing, drone hardware integration, and flight-control system development. Using the Arduino IDE and C/C++, the project strengthened our understanding of how microcontrollers coordinate electronic components in a drone system and provided a foundation for further exploration of robotics, automation, and unmanned aerial vehicle technology.
